这个项目做什么

蒙企链探面向内蒙古食品产业研学。学生端是 UniApp X 微信小程序，运营后台是 Vue 3，后端是 NestJS、Prisma 和 PostgreSQL。

完整链路包括研学预约、现场导览打卡、知识任务、成果档案、积分成长、文创商城和权限后台。

自己做了什么

  • 设计并实现研学预约、打卡、任务、证书和积分兑换。
  • 同时做学生端小程序、运营后台和后端数据模型。
  • 自己完成部署和联调，把小程序、后台和后端接到同一套接口上。

技术栈

  • NestJS
  • Prisma
  • PostgreSQL
  • UniApp X
  • Vue 3
  • Redis
